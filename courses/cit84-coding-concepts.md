## Course Objectives Revision

| **Obj #** | **Proposed Text** | **Rationale for Change** |
| :--- | :--- | :--- |
| **1** | **Deconstruct complex computational problems into discrete, step-by-step algorithms using standardized flowcharts and pseudocode.** | Establishes foundational problem-decomposition skills without getting bogged down in syntax rules or compiler errors. |
| **2** | **Design, evaluate, and trace conditional execution flows and multi-alternative decision branches using boolean logic and truth tables.** | Teaches students how programs make decisions, ensuring they understand branching paths before implementing them in code. |
| **3** | **Construct and manage repetition structures (loops) while accurately tracking variable state changes using manual trace tables.** | Develops dry-running and manual code-tracing skills ("trace tables over compilers") to eliminate infinite loop errors and logic bugs. |
| **4** | **Structure modular logic patterns by defining functions with explicit inputs (parameters), variable scopes, and return outputs.** | Introduces functional decomposition and data encapsulation as universal programming concepts. |
| **5** | **Critically evaluate and audit AI-generated pseudocode or logic routines, manually verifying execution correctness.** | Implements human-in-the-loop engineering, ensuring students can debug and verify AI logic outputs rather than blindly accepting them. |

## Lecture & Lab Content Revision

| **Topic Area** | **Proposed Sub-topics** | **Rationale for Change** |
| :--- | :--- | :--- |
| **Computational Thinking & Problem Deconstruction** | Problem Decomposition, Pattern Recognition, Abstraction, Algorithmic Design, and Standardized Flowcharting (symbols, decision blocks, boundaries). | Moves students away from guessing code syntax to systematically planning logic visually before writing scripts. |
| **Data Representation & Core Structures** | Memory Slots, Assignment, Primitive Data Types (strings, ints, floats, booleans, null/undefined), Conditional Logic (`if/else`, `switch`), and Truth Tables. | Establishes clear mental models for how data is stored and manipulated in system memory. |
| **Repetition & Control Flow** | Pre-test/Post-test Loops (`while`, `do-while`), Count-Controlled Loops (`for`), State Management (counters, accumulators, sentinels), and Trace Tables. | Replaces compiler reliance with manual dry-running, forcing students to step through execution paths line-by-line. |
| **Modular Design & "Human-in-the-Loop" Logic** | Function Parameters, Return Values, Scope Boundaries (local vs. global), and Socratic AI Debugging & Verification. | Introduces functional programming architecture and teaches students how to use AI as a logic tutor while retaining human accountability. |
