---

## I. Diversity, Equity, and Inclusion (DEI) Statement
Faculty promote diversity, equity, and inclusion in CIT 94 through student-centered instructional practices that support learners with varied technical backgrounds, preparation levels, and educational goals. Course materials and evaluations are structured to eliminate historical barriers to advanced technical capstones by providing supportive bridge labs and clear architectural scaffolding for full-stack, agentic web applications. By integrating structured AI agent orchestration, local vector search, and open-source models, the curriculum democratizes access to cutting-edge software engineering, enabling all students to build enterprise-level applications regardless of personal hardware constraints or financial resources. By replacing high-stakes written exams with authentic, supportive technical walkthroughs and live verbal defenses, the course accommodates neurodiverse learning styles and reduces evaluation anxiety while building professional communication confidence. Course projects are consistently connected to diverse, real-world community needs across the Central Valley, and zero-cost digital resources ensure financial barriers do not impede student equity, fostering an inclusive environment for all emerging tech professionals entering the modern workforce.

---

## II. Consolidated Student Learning Outcomes (SLOs)

Upon successful completion of CIT 94, students will be able to:

1. **Architect Full-Stack Agentic Web Systems:**
   Design, construct, and deploy full-stack web applications that integrate autonomous AI agents, multi-agent networks, local vector databases (RAG), and structured JSON tool-calling interfaces to resolve complex software constraints.

2. **Audit System Integrity & Conduct Live Technical Defenses:**
   Audit AI-driven application logic for security vulnerabilities, API token budgeting, and state correctness, while defending code architecture and operational choices through live technical interviews and verbal code reviews.
