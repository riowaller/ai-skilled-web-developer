# Course-Level Revision Rationale: Specific Curricular Changes

### CIT 82: Introduction to AI and Web Development
* **What Changed:** Replaced legacy introductory web page authoring and manual hosting setup with prompt engineering fundamentals, modern browser-based cloud IDE tooling, and introductory HTML/CSS structures.
* **Why the Change Was Made:** Entry-level students need early exposure to the tools industry actually uses. Moving away from manual local setup to cloud environments removes early technical frustration, while introducing AI prompt framing establishes modern computational thinking from day one.
* **Key Accreditation/Title 5 Alignment:** Clarified introductory SLOs around structured prompt formulation, ethical considerations of AI, and accessible web page semantics.

---

### CIT 85: HTML and CSS
* **What Changed:** Shifted focus from basic inline styling and deprecated layout models to modern semantic HTML5 architecture, CSS Grid/Flexbox layouts, and WCAG accessibility standards.
* **Why the Change Was Made:** With automated site builders handling basic templates, employers demand interface specialists who understand semantic hierarchy, screen-reader compliance, and responsive layouts that function across any screen dimension.
* **Key Accreditation/Title 5 Alignment:** Updated objectives to emphasize accessibility audits, mobile-first responsive mechanics, and standardized DOM structuring.

---

### CIT 84: Foundational Coding Concepts
* **What Changed:** Replaced theoretical computer science algorithm jargon with applied, language-agnostic logic workflows: visual flowcharting (ANSI/ISO standards), structured pseudocode, and line-by-line execution trace tables.
* **Why the Change Was Made:** Students often struggle in JavaScript because they are trying to learn syntax and program logic simultaneously. Isolating logic from syntax allows students to master control flow, scoping, and boundary conditions first.
* **Assessment Innovation:** Introduced the oral logic review and execution trace table defense, ensuring students dry-run their own logic and use AI strictly as a Socratic tutor rather than an answer generator.

### CIT 94: Agentic AI (Full-Stack Capstone)
* **What Changed:** Re-titled and modernized the course from legacy standalone server-side scripting (**Node.js**) to **Agentic AI**, repositioning it as the comprehensive full-stack capstone for the sequence.
* **Why the Change Was Made:** 
  * **Industry Evolution Beyond Basic Runtimes:** Server-side JavaScript runtime mechanics (Node.js) are no longer terminal, isolated skills; backend environments now serve as the runtime foundation for autonomous agent execution loops, API orchestration, and external service communication.
  * **Full-Stack Application Integration:** Rather than teaching server scripting in a silo, students use backend execution environments to build production-ready applications that bind client-side interfaces to business databases, external REST APIs, and multi-agent coordination frameworks.
  * **Direct Workforce Competitiveness:** Transforming the course into *Agentic AI* directly prepares students for emerging industry titles (e.g., AI-augmented web developer, integration specialist) by teaching structured tool-calling, schema validation, rate-limiting, and error-resilient autonomous loops.
* **Curricular Impact & Rigor:** 
  * Retains essential backend principles—asynchronous processing, environment security, and server routing—while elevating the student's role from a repetitive boilerplate coder to a system architect.
  * Culminates in a mandatory **1-on-1 live technical code defense**, where students verbally trace backend agent execution flows, explain JSON tool-calling schemas, and validate data integrity under direct instructor evaluation.
