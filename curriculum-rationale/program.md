# Program-Level Revision Rationale: Systemic Curricular Changes

### 1. Transition to the "Web Developer" Pathway
* **What Changed:** Re-architected the existing web development sequence into a unified, modern pipeline:  
  **CIT 82 (Intro to AI & Web) → CIT 85 (HTML/CSS) → CIT 84 (Logic) → CIT 93 (JavaScript) → CIT 94 (Agentic AI)**.
* **Why the Change Was Made:** Industry demand shifted sharply from manual static site coding to full-stack system orchestration. Employers need technicians who can connect web applications to existing business data, validate APIs, and supervise automated workflows.
* **Curricular Benefit:** Establishes an identifiable, marketable program identity that signals cutting-edge workforce readiness to prospective students, four-year transfer partners, and regional employers.

---

### 2. Scaffolded Progression (Decoupling Syntax from Logic)
* **What Changed:** Sequenced **CIT 84 (Foundational Coding Concepts)** directly alongside/before **CIT 93 (JavaScript)**, reframing CIT 84 around language-agnostic logic, flowcharts, pseudocode, and trace tables.
* **Why the Change Was Made:** Historical data showed student drop-off in programming courses when syntax rules and algorithmic thinking were introduced concurrently. Decoupling logic allows students to master problem decomposition before battling JavaScript syntax.
* **Curricular Benefit:** Directly increases student persistence, retention, and success rates through the technical core of the certificate and degree.

---

### 3. Program-Wide Assessment Modernization (Oral Code Defenses)
* **What Changed:** Integrated structured **1-on-1 live technical interviews and oral code defenses** across CIT 84 and CIT 94, replacing traditional take-home exams and isolated asynchronous coding submissions.
* **Why the Change Was Made:** Generative AI tools have made traditional unproctored homework assignments obsolete for evaluating authentic mastery. Requiring students to verbally explain execution paths, defend architectural patterns, and dry-run trace tables verifies true authorship.
* **Curricular Benefit:** Directly prepares students for industry technical interviews, instills communication confidence, and guarantees academic integrity without relying on invasive proctoring software.

---

### 4. Zero Textbook Cost (ZTC) & Equitable Toolchain Standards
* **What Changed:** Standardized the entire sequence on open-source documentation (MDN, official framework specs) and browser-based cloud development environments (e.g., GitHub Codespaces).
* **Why the Change Was Made:** Outdated commercial textbooks fail to keep pace with rapid web technologies and impose severe financial barriers. Local software installations often fail on varied student hardware (Chromebooks, older laptops), creating inequity on Day 1.
* **Curricular Benefit:** Complies with California ZTC mandates, supports Universal Design for Learning (UDL), and guarantees every student has an identical, functional development sandbox in the browser from the first week of class.

---

### 5. Shift from Theoretical CS to Applied Business Integration
* **What Changed:** Aligned advanced coursework (CIT 94) with applied business data integration, schema validation, and secure API tool-calling rather than theoretical mathematical modeling or pure computer science algorithms.
* **Why the Change Was Made:** As a community college CTE program, our primary mission is direct employability. Regional employers (healthcare, agriculture technology, government, logistics) need developers who can build secure, reliable web tools that interact with real relational databases and external business services.
* **Curricular Benefit:** Clear differentiation from four-year CS transfer pathways, providing an immediate career-entry off-ramp for career education students while retaining transferability options.
