# Program & Course Naming Options & Consensus Record

## 🎯 The Naming Strategy
We balanced **Industry Branding** (attracting students with AI/Agentic skillsets) against **Transfer Compatibility** (ensuring CSU Fresno and regional partners recognize core courses for clean articulation) and **Catalog Display Mechanics** (preventing backend routing glitches).

---

## 🏛️ Option 1: The "AI-Forward" Approach
*Focuses on maximum marketability and clear program identity.*

| Level | Title Candidate | Pros | Cons |
| :--- | :--- | :--- | :--- |
| **Program** | AI-Skilled Web Developer | High industry appeal; clear modern brand. | May feel "trendy"; creates catalog system display routing artifacts. |
| **CIT 82** | Intro to AI & Web Development | Accurate to new content. | None. |
| **CIT 93** | AI-Augmented JavaScript | Signals modern workflow (TDD/AI). | **High risk** for CSU transfer articulation. |
| **CIT 94** | Advanced Agentic AI | Perfect for an uncompromised capstone. | None. |

---

## 🏗️ Option 2: The "Functional/Modern" Approach
*Focuses on long-term stability while implying modern methods.*

| Level | Title Candidate | Pros | Cons |
| :--- | :--- | :--- | :--- |
| **Program** | Modern Web Development | Sounds professional and permanent. | "Modern" is a relative term that ages quickly. |
| **CIT 82** | Web Development Foundations | Very safe for transfer. | Doesn't highlight the foundational AI shift. |
| **CIT 93** | JavaScript Programming | Maximum transfer compatibility. | Doesn't signal the TDD/Mechanical Shop focus. |
| **CIT 94** | Full-Stack Web Workflows | Professional and descriptive. | A bit generic for an advanced AI capstone. |

---

## 🤝 Option 3: The Final Consensus Strategy (Locked In)
*Preserves the original Program title for catalog/transfer stability while embedding AI branding into the entry gate and advanced capstone.*

| Level | Final Selected Title | Rationale & Consensus Status |
| :--- | :--- | :--- |
| **Program** | **Web Developer** | 🔒 **LOCKED IN.** Preserves original title as-is. Maintains clean catalog continuity, avoids backend display routing constraints (`Formerly known as...`), and protects regional CTE brand recognition. |
| **CIT 82** | **Intro to AI & Web Development** | 🔒 **LOCKED IN.** Bold entry point highlighting prompt engineering, web basics, and environment literacy. |
| **CIT 85** | **HTML and CSS** | 🔒 **LOCKED IN.** Preserved title ensuring zero transfer friction for structural web layouts. |
| **CIT 84** | **Foundational Coding Concepts** | 🔒 **LOCKED IN.** Re-imagined as language-agnostic logic, flowcharts, pseudocode, and trace tables. |
| **CIT 28** | **SQL** | 🔒 **LOCKED IN.** Preserved relational data modeling foundation. |
| **CIT 93** | **JavaScript** | 🔒 **LOCKED IN.** Maximum safety for CSU articulation; keeps syntax isolation core intact. |
| **CIT 94** | **Advanced Agentic AI & Web Application Architecture** | 🔒 **LOCKED IN.** Strong program capstone focusing on autonomous AI agents, tool-calling, multi-agent networks, and verbal code defense. |

---

## 🔒 Resolved Discussion Points
1. **Program Name Continuity:** The workgroup confirmed that keeping **Web Developer** as the program title avoids catalog display bugs while allowing the underlying taxonomy shift (**CIP 11.0104 - Informatics**) to capture state funding and AI skill differentiation.
2. **Protecting Core Transfer:** Leaving **CIT 93 (JavaScript)** with its traditional title guarantees zero articulation friction with CSU Fresno, while the course outline of record (COR) infuses our "Mechanical Shop" and TDD pedagogy inside the classroom.
3. **Capstone Distinction:** Reclaiming **CIT 94** as the dedicated 4th-semester capstone provides the exact space needed for high-impact AI/Agentic branding without endangering lower-tier transfer paths.
